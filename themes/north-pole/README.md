# North Pole theme

Copyright © 2026 Jaime C Acosta.

The original winter town, Santa's castle, six interiors, three explorers, and MIDI soundtrack. The manifest is `theme.json`; referenced artwork, sprites, and audio live in `public/maps`, `public/sprites`, and `public/audio`.

Import `theme-packs/north-pole.zip` through **Manage → Theme → Import / Export → Import theme**. This pack contains theme metadata and assets, with no challenges or accounts. Existing account and map IDs remain compatible with Agentic Circuit.

Build both included theme ZIPs with `npm run themes:build`. See [THEMES.md](../../THEMES.md) for the format and [MAP_GUIDE.md](../../MAP_GUIDE.md) for map coordinates.
