# North Pole theme

Copyright © 2026 Jaime C Acosta.

The original winter town, Santa's castle, six interiors, three explorers, and MIDI soundtrack. The manifest is `theme.json`; referenced artwork, sprites, and audio live in `public/maps`, `public/sprites`, and `public/audio`.

Import `theme-packs/north-pole.zip` through **Manage → Import & backup → Theme, content & backups → Import theme**. This pack contains theme metadata and assets, with no challenges or accounts. Existing account and map IDs remain compatible with Agentic Circuit.

Build both included theme ZIPs with `npm run themes:build`. See [THEMES.md](../../THEMES.md) for the format and [MAP_GUIDE.md](../../MAP_GUIDE.md) for map coordinates.

## Beginner demo adventure

Open **Manage → Theme → Theme library → North Pole → Load demo adventure**. The confirmation imports its matching world and example content together. It replaces the active challenge collection; accounts, teams, and recorded scores stay saved. Export your current content first if you want to keep a reusable copy. **Use this theme** still changes only the world, without demo locks. Neither pack includes accounts, passwords, or student answers.

The demo has ten simple challenges (nine visible, one hidden instructor example): star markers, 1×1/2×2/3×3 boss encounters, automatic and instructor grading, case-sensitive flags, free and paid hints, a downloadable text file, and an optional hint priced in a bonus reward. Guides have branching dialogue, and the host appears after the final boss. Both variants now have two original MIDI tracks that shuffle during playback and can be muted.

Follow this route:

1. Talk to the guide at town (18,17), then solve the starter at (18,19) for the **red key**.
2. Solve the star at town (11,19) for the **shortcut incantation**. Touch the shortcut at (16,21) to travel to Cocoa Cottage and return using its exit.
3. Visit Toy Workshop and solve the **1×1 boss** at (15,15) for the **gold key**.
4. Use that key to enter Evergreen Elf House and solve the **2×2 boss** at (20,12). Its prerequisites are the starter route and incantation challenge.
5. Download the note in Post Office at (20,12) and enter its flag with exact capitalization.
6. Use the red key to enter Santa’s castle. The **3×3 boss** starts at (19,10) and unlocks after the 2×2 boss and file challenge. Its full nine-tile footprint is usable ground.
7. Submit the written reflection at castle (25,18). An admin grades it under **Challenges → Submissions**. The host at (25,16) is now available to talk to.

The Bakery bonus at (20,12) awards a green key. Its answer-reveal hint costs 5 points and forfeits that optional key; no required route uses it. The Cocoa Cottage has another short question at (20,12). The hidden example at town (29,8) can be enabled in the challenge editor.

Portable files, generated by `npm run themes:build`:

- `theme-packs/north-pole.zip`: reusable world/artwork/music and guide, with no demo locks or challenges.
- `theme-packs/north-pole-demo-theme.zip`: world with matching locks, shortcut, and progression dialogue.
- `theme-packs/north-pole-demo-content.zip`: challenges, answers, rewards, hints, and downloads.

To import manually, choose the demo theme ZIP plus its **Matching content ZIP** in Import & backup → Theme, content & backups. Keep these paired so every lock has its reward source. Author questions in `demo-challenges.yaml`; `demo-content.json` is generated for the runtime. World changes are in `demo-theme.json`; edit the unlocked variant separately in `theme.json`. IDs use theme-specific `np-demo-v2-` / `ac-demo-v2-` prefixes to keep these examples distinct from previous challenges. Reimporting the same demo keeps its existing completion history; change IDs when starting a fresh assessment.

These are practice questions with public source answers, not a secure exam. Replace text, flags, hints, downloads, and IDs before using them for a real test.
