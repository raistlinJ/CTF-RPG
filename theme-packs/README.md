# Importable CTF-RPG themes

Copyright © 2026 Jaime C Acosta.

- **north-pole.zip**: the Christmas town and Santa's castle.
- **agentic-circuit.zip**: the computing and Agentic AI campus.

These ZIPs include each theme's manifest, map artwork, sprites, and MIDI files. They contain no accounts, challenges, or progress. Import either as an administrator through **Manage → Theme → Import / Export → Import theme**.

Source manifests live in `themes/`; assets live in `public/`. After editing source manifests/assets, run `npm run themes:build` to regenerate these packs.
